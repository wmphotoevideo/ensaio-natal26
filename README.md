# Ensaio de Natal 2026 - Gestão de clientes

App de gestão do ensaio fotográfico de Natal 2026: painel, clientes, agenda, pós-produção,
mensagens de WhatsApp, financeiro e ajustes. Tudo em um único arquivo (`index.html`), sem build.

## Como usar
- Abra o `index.html` no navegador, ou publique no GitHub Pages
  (Settings > Pages > Deploy from a branch > main / root).

## Onde ficam os dados
- Fora do Claude, os dados ficam salvos **só no navegador de quem usa** (localStorage).
- Cada computador ou celular tem sua própria lista de clientes. Não há sincronização entre fotógrafos.
- Use **Ajustes > Backup completo** para guardar uma cópia dos dados.
- Limpar os dados do navegador apaga os clientes. Faça backup com frequência.

## Privacidade
- O código do app é público se o repositório for público, mas os dados dos clientes
  nunca vão para o GitHub: ficam só no navegador.
- Se quiser, deixe o repositório privado.
